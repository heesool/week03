# Issue
环境：Windows, std-greet
复现命令：`sdt-greet --name " "`
期望结果：识别到姓名为空时，程序不输出问候，并返回非0值，提示输入信息错误
实际结果：仍输出`Hello, !`且返回为0,正常退出

# 提交信息
拒绝仅包含空白字符的姓名
问题：sdt-greet 未校验 name 是否只包含空白字符，导致无效输入正常执行。
解决方案：增加姓名参数空白校验，若姓名为空，不输出问候语，返回非0错误码。

# 评审意见
Blocking: 当前代码在传入空白姓名时依旧输出问候语，正常退出。该行为会造成误判，调用方无法识别参数非法。建议补充参数校验，空白姓名场景禁止输出问候并返回错误码，请修改后重新提交。
